# jejakcommuter (Jecom)

Teman perjalanan pengguna transportasi umum Jabodetabek: KRL, MRT, LRT, dan TransJakarta dalam satu aplikasi.

**Web:** https://jejakcommuter.com/app  
**Android:** unduh di https://jejakcommuter.com/unduh

## Fitur
- Rute dan perkiraan jadwal KRL, MRT, LRT, dan TransJakarta
- Laporan kondisi jalur dari penumpang yang benar-benar ada di stasiun atau di dalam kereta
- Chat umum per jalur, grup, dan chat dengan teman
- Berbagi lokasi perjalanan dengan teman atau grup
- Urgent: rumah sakit, klinik, dan apotek terdekat
