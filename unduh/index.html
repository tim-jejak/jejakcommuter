Rute KRL, MRT, LRT, dan TransJakarta. Gratis untuk Android.

Unduh aplikasi (7 MB) Belum mau pasang? Coba di browser

CARA PASANG

  1. Tekan Unduh aplikasi, lalu tunggu sampai selesai.
  2. Buka file jejakcommuter.apk dari notifikasi atau folder Download.
  3. Kalau diminta, tekan Setelan lalu nyalakan Izinkan dari sumber ini, kemudian kembali.
  4. Tekan Instal. Kalau muncul peringatan Play Protect, pilih Tetap instal.

Peringatan itu muncul karena aplikasi belum ada di Play Store, bukan karena berbahaya.
